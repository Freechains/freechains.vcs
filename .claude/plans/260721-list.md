# List command: annotate post state (beg / revoked / normal)

Make `list` distinguish post kinds instead of printing bare
hashes, so a client can tell revoked and beg posts apart.

## Current behaviour (`list.lua`)

| subcommand   | source          | output |
|--------------|-----------------|--------|
| `list order` | `G.order`       | bare hashes (posts + likes) |
| `list begs`  | `refs/begs/`    | pending beg hashes |
| `list dag`   | `G.order`       | ASCII DAG |

Begs are ALREADY separate (`refs/begs/`), because a `--beg`
post is `reset --hard` off main and parked on a ref
(`post.lua:91-98`). Revoked posts live in `G.order` and are
detected via `is_revoked(p)`.

## DECISION (2026-07-22): annotate only MIXED listings

Split on homogeneous vs mixed streams:

| listing        | content      | annotation |
|----------------|--------------|------------|
| `list begs`    | all begs     | none (homogeneous) — keep separate |
| `list revokes` | all revoked  | none (homogeneous) — NEW subcommand |
| `list order`   | mixed        | ` R` suffix on revoked |
| `list dag`     | mixed        | `~hash~` on revoked |

- Begs stay separate (`refs/begs/`), NOT merged.
- Homogeneous listings need no flag (the subcommand IS the
  filter); suffixes only where the stream mixes kinds.

### `list order` format

Revoked lines become `<hash> R` (hash first, space-separated),
so field-1 parsers (`awk '{print $1}'`) survive; only revoked
lines change. A pipeline feeding hashes into `get` carries ` R`
on revoked posts — acceptable (fetching a revoked payload errors
anyway).

### `list dag` format

Revoked node renders as `~<short>~` instead of `<short>`.
CAUTION: the dag branch is flagged "AI-gened, not properly
reviewed" (`list.lua:16`); tildes add 2 chars to the 7-char
short hash, so `SHORT` / `set_at` centering must account for the
width or alignment drifts.

| `list.lua` | `ARGS.order` branch | append ` R` when `is_revoked(G.posts[h])` |
| `list.lua` | `ARGS.dag` branch | wrap revoked short hash as `~..~`, fix width math |

Notes:

- Likes in `G.order` are never revoked -> no suffix (guard on
  `G.posts[h]` existing).
- `is_revoked` lives in `common.lua` (global), available here.
- A revoked post keeps its hash in order (metadata stays); the
  flag only annotates, does not remove it.

### Suggested order of work

1. `list revokes` + ` R` in `list order` (simple, safe).
2. `~hash~` in `list dag` (isolated, cosmetic, riskier branch).
