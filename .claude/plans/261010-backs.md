# Bug: `backs` re-walks merges exponentially

# Symptom

- found by 2606-sims `p2p/p2p.lua`, usenet local first
    - mids sync every 6 h, leaves every 24 h
    - 843 posts, 1540 commits, 699 merges
- one `recv` pull took 115-137 s
- `/x/papers/2606-sims/.claude/plans/260924-topology.md`

# Profile (one pull, p40 recv p05)

- total 852 s (with hooks), git only 2 s
- `action.lua:190` `M.backs`: 848 s, 39 calls
- inner `rec`: 24.7M calls

# Cause

- `see` marks only actions
- a sync merge reached by k paths is walked k times
- merges of merges: paths grow exponentially with depth

# Fix

- mark every visited commit in `see`, not only actions
- recurse into a merge only on its first visit
- result set unchanged: same actions, still sorted

# Evidence (patched copy, same pull)

- 115 s -> 2.75 s
- same HEAD `899c1ad`, 1539 commits
- same `list order` md5, refs md5, reps
