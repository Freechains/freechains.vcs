# Charge Begs on Admission

# Problem

- rule 2 charges 500 per new post, refunded within 12h
- a beg skips the charge: rules.lua ln 649 bumps the author by 0
  when the like admits it
- but the refund record IS created there (maturity "00-12"), so the
  author is refunded 500 that was never charged
- verified with the CLI: dave begs, alice likes 4000
    - after the like: 1800
    - after 12h: 2300 (free 500)
    - after 24h: 3300
- the paper carries the gap as "(except begs)" in Table 3 rule 2

# Goal

- a beg pays rule 2 like any post, at the moment the like admits it
- expected: 1300 after the like, 1800 after 12h, 2800 after 24h

- run it, confirm it fails on 1800 / 2300 / 3300

# Open question (decide before coding)

- the charge can exceed the credit: a 500 like (rule 4.a minimum)
  yields the author 225 after tax and split, below the 500 charge
- options:
    - (a) let begs go negative, a one-off debt
    - (b) require the admitting like to cover the charge:
      n * 0.9 / 2 >= 500, i.e. n >= 1112
    - (c) charge min(500, credited)
- recommendation: (b), uniform rule 2, no-debt invariant kept, and a
  like under 1112 is not a serious welcome anyway
- answer: (a), 2026-10-02: a one-off debt, no new minimum
