# Slash Aliases: `#chat` -> `/chat`

- shell-safe alias prefix `/` (no quotes), cid without prefix
- for now only `#` -> `/`: no `$`/`@` types in aliases
- `chain <x>`: any path under `chains/`, so `/alias`, `alias`,
  `<cid>`, `/<cid>` all resolve; only `chains add` demands the `/`
- remote paths: `host/<alias>` and `host/<cid>` both resolve (fs)

# Layout

- `chains/<genesis>/`          bare repo (was `chains/#<genesis>/`)
- `chains/chat -> <genesis>/`  alias symlink (flat)

# Code

- `chains.lua`
    - first char must be `/`, else `expected '/'`
    - any other `/`: `nested alias not supported`
    - `print(gen)`, `ln -s <gen>/`, `readlink`, `find -maxdepth 1`
- `common.lua` `URL()`
    - alias appended only when raw has no `/` (bare `host[:port]`)
    - bare `<cid>` alias gets a leading `/` before appending
    - any path or url is explicit: `localhost:8331/talks`
- `chain/init.lua`: single `refs/genesis` check, no alias/cid split

# Docs / Tests

- `doc/cli.md`: Chain URLs prefix/suffix, `/chat` examples
- `doc/guide.md`, `guide.sh`, `README.md`: `/chat`, cid w/o `#`
- `tst/*.lua`: `'#x'` -> `/x` unquoted, cid regex `^%x+$`, len 40
- `cli-chains.lua`: cid forms, clone by cid path, alias errors
