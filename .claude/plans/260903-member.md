# Scope: ALL member (no split)

- DECIDED: everything renames -- the performer of an action
  is also just a member acting
- `entry.author` -> `entry.member` (the action's signer)
- `revoke = { author, others }` -> `{ member, others }`
  (the member's own revoke vs the community)
- `act.author` (vote target) -> `act.member`
- `G.authors` -> `G.members` (snapshots break, no back
  compat, as genesis/maturation before)
- commit message keyword: `author <pub>` -> `member <pub>`
  (WIRE: consensus-visible bytes)
- CLI: `like/dislike <n> member <pub>`, `reps member`,
  `reps members`; error strings follow
- metadata output: `author` -> `member`; `sign` stays
- comments/headers wording follows

# What does NOT rename

- git's own commit header bytes (`\nauthor - <->`: parsing
  of GIT format, not our vocabulary)
- `sign`/`SSH.signer`: the signature, not the ledger
- `C.anon` ("anonymous"): a member name, unchanged
- plans/ and HISTORY historical text: untouched
