# Measured 26/08/18-19

- scripts kept outside the repo (scratchpad, `--root` only)
- snapshots are QUADRATIC: one per commit, each serializing
  the whole `G`, so total ~= 0.25 * N^2 KB
- confirmed to N=10000 (grow.sh, one post per second):

| posts | states  | .git    | share | newest | build  |
|-------|---------|---------|-------|--------|--------|
|   100 | 2.7 MB  | 6.7 MB  |  40%  |  51 KB |    6 s |
|  1000 | 250 MB  | 283 MB  |  88%  | 0.5 MB |   74 s |
|  2000 | 996 MB  | 1.03 GB |  97%  | 1.0 MB |  173 s |
|  5000 | 6.2 GB  | 6.24 GB | 99.4% | 2.5 MB |  582 s |
| 10000 | 24.8 GB | 24.9 GB | 99.9% | 5.1 MB | 1648 s |

- per-snapshot cost exactly linear: ~0.5 KB per action
- LATENCY too, not only disk: each post writes a full
  snapshot (5 MB at 10k); posts slowed ~14/s -> ~6/s
- prune keeps W = min(fork.actions, actions in fork.time)
  snapshots <= 100, each ~0.5*N KB:
    -  1k actions: 250 MB ->  50 MB  (5x; W=100)
    -  5k actions: 6.2 GB -> 250 MB (25x)
    - 10k actions: 25 GB  -> 510 MB (49x)
    - slow chains keep fewer (time axis binds): better cut
- residual is O(W*N), still linear in N; constant space
  would need incremental snapshots (different design)

# A1: restrict `abandon` to the window (do first)

- refuse an aid below the hardfork window: same boundary
  pruning uses, so the two can never overlap
- rationale: abandon exists to escape a hard fork, and a
  fork is always recent
- error: `chain abandon : settled action`
- drops the need to make snapshots recomputable

## Why: `STATE.read` asserts on a miss

- `state.lua:31` -> `"bug found : no snapshot"`, no recompute
- tolerant readers (pruning is already safe for them):
    - `sync.lua:227` replay seeding just replays instead
    - `consensus.lua:232` writes what is missing
- fatal reader: `abandon.lua` resets HEAD onto an arbitrary
  old commit, then `init.lua:24` loads HEAD's snapshot for
  EVERY later command -> all of them die
- won't do: `STATE.read` replaying forward from the nearest
  ancestor (E0); A1 removes the case

# E stage 2: prune `.git/states/`

- `sweep` (stage 1 = `git gc --prune=now`) gains stage 2:
  delete snapshots outside the settled window
- settled = below the hardfork window (fork.time/fork.actions)
- keep: window snapshots + the tips sync reads (HEAD, oct
  candidates); a missing interior snapshot must be
  recomputable or unreachable
- payoff: O(N^2) -> O(W*N), since each kept snapshot is still
  O(N); a ~100x cut, not constant space
