# Charge Begs on Admission

# Problem

- rule 2 charges 500 per new post, refunded within 12h
- a beg skips the charge: rules.lua ln 649 bumps the author by 0
  when the like admits it
- but the refund record IS created there (maturity "00-12"), so the
  author is refunded 500 that was never charged
- verified with the CLI: dave begs, alice likes 4000
    - after the like: 1800
    - after 12h: 2300 (free 500)
    - after 24h: 3300
- the paper carries the gap as "(except begs)" in Table 3 rule 2

# Goal

- a beg pays rule 2 like any post, at the moment the like admits it
- expected: 1300 after the like, 1800 after 12h, 2800 after 24h

# Failing test first

- tst/cli-begs.lua: new case, before any code change
    - pioneer alice; dave begs; alice likes 4000
    - assert dave == 1300 right after the like
    - assert dave == 1800 after 12h
    - assert dave == 2800 after 24h
- run it, confirm it fails on 1800 / 2300 / 3300

# Design

- rules.lua, like on a beg (ln 645-651): bump the author by
  -C.reps.cost instead of 0
- the author always affords it: the like just credited n/2 after
  tax, and n >= 500 (rule 4.a), so n/2 * 0.9 >= 225... NOT enough
    - a 500 like yields 225 to the author, below the 500 charge
    - decide: (a) allow the charge to go negative for begs only, or
      (b) require the like to cover the charge (n*0.9/2 >= 500,
      i.e. n >= 1112), or (c) charge min(cost, credited)
    - (b) is the cleanest: a beg needs a like of at least 1112
- unsigned begs (no author) keep bumping nothing

# Files

- tst/cli-begs.lua: the failing case above
- src/freechains/chain/rules.lua: the bump, and the minimum like
  if (b)
- doc/guide.md: the beg example numbers
- paper: Table 3 rule 2 without "(except begs)"; Listing 5 dave 1300
